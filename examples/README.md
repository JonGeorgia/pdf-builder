# Пример

Эта папка — готовый пример использования PDFuse.

## Что внутри

- `example.md` — исходный Markdown-документ.
- `style/style.css` — CSS-стиль, описывающий оформление PDF.
- `images/` — изображения, на которые ссылается `example.md`.
- `example.pdf` — **готовый результат**. Можно посмотреть, не запуская программу.

## Как воспроизвести

1. Откройте PDFuse.
2. Нажмите «Выбрать папку» и укажите эту папку (`examples/`).
3. Нажмите «Сгенерировать PDF».
4. Рядом с `example.md` появится `example.pdf` — он должен совпасть с готовым.

## Как использовать стиль в своих документах

Скопируйте `style/style.css` в свой проект и адаптируйте под свои нужды.
