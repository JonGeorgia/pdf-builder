about_text=PDFuse — программа для генерации PDF-документов из Markdown-файлов и обратной конвертации из PDF в Markdown.\nПрограмма позволяет создавать и редактировать PDF файлы (инструкции, образовательные программы, книги и прочие документы) путем размещения в создаваемых PDF документах их исходников в формате Markdown которые извлекаются при необходимости внести изменения в PDF.\n\nОсновные возможности:\n• Конвертация Markdown в PDF: с применением пользовательских CSS-стилей для создаваемых PDF, и автоматическим размещением изображений которые должны находится в папке images, а ссылки на них содержаться в Markdown. Стиль описывается в отдельном CSS документе размещаемом в той же папке что и Markdown документ.\n• Пакетная обработка: конвертация нескольких Markdown файлов в выбранной папке одновременно с применением ко всем одного стиля описанного в CSS файле.\n• Обратная конвертация: полная конвертация с изображениями и стилями из PDF в Markdown (возможно, если PDF создан PDFuse), или извлечение только текста (для любых PDF содержащих текст *(извлечение текста из преобразованного в рисунок документа программа не выполняет)).\n• Использование созданных PDF с ИИ моделями: Созданные PDF документы остаются машиночитаемыми что позволят их использовать в RAG-системах (Retrieval-Augmented Generation).\n• Поддержка языков: русского, английского, немецкого и французского языков.
