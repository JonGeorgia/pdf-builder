about_text=PDFuse — un programme pour générer des documents PDF à partir de fichiers Markdown et la conversion inverse de PDF en Markdown.\nLe programme permet de créer et modifier des fichiers PDF (instructions, programmes éducatifs, livres et autres documents) en intégrant leurs fichiers sources Markdown dans les documents PDF créés, qui peuvent être extraits lorsque des modifications du PDF sont nécessaires.\n\nFonctions principales :\n• Conversion Markdown en PDF : avec des styles CSS personnalisés pour les PDF créés et placement automatique des images qui doivent se trouver dans le dossier images, avec des liens vers celles-ci contenus dans le Markdown. Le style est décrit dans un fichier CSS séparé placé dans le même dossier que le document Markdown.\n• Traitement par lots : conversion simultanée de plusieurs fichiers Markdown dans un dossier sélectionné, en appliquant à tous un seul style décrit dans le fichier CSS.\n• Conversion inverse : conversion complète avec images et styles de PDF en Markdown (possible si le PDF a été créé par PDFuse) ou extraction de texte uniquement (pour tout PDF contenant du texte *(le programme n'extrait pas le texte des documents convertis en images)).\n• Utilisation des PDF créés avec des modèles d'IA : Les documents PDF générés restent lisibles par machine, permettant leur utilisation dans les systèmes RAG (Retrieval-Augmented Generation).\n• Langues prises en charge : russe, anglais, allemand et français.
