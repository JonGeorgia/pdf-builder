about_text=PDFuse — a program for generating PDF documents from Markdown files and reverse conversion from PDF to Markdown.\nThe program allows you to create and edit PDF files (instructions, educational programs, books and other documents) by embedding their Markdown source files into the generated PDF documents, which can be extracted when changes to the PDF are needed.\n\nMain features:\n• Markdown to PDF conversion: with custom CSS styles for the generated PDFs, and automatic placement of images that must be located in the images folder, with links to them contained in the Markdown. The style is described in a separate CSS file placed in the same folder as the Markdown document.\n• Batch processing: conversion of multiple Markdown files in a selected folder simultaneously, applying a single style described in the CSS file to all.\n• Reverse conversion: full conversion with images and styles from PDF to Markdown (possible if the PDF was created by PDFuse), or text-only extraction (for any PDF containing text *(the program does not extract text from documents converted to images)).\n• Use of created PDFs with AI models: Generated PDF documents remain machine-readable, allowing their use in RAG systems (Retrieval-Augmented Generation).\n• Language support: Russian, English, German and French.
