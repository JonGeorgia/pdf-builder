PDFuse - Build PDF from Markdown / Создание PDF из Markdown
===========================================================

QUICK START / БЫСТРЫЙ ЗАПУСК
----------------------------
EN: Run the program without installation:
RU: Запустите программу без установки:
    ./PDFuse-x86_64.AppImage


INSTALL TO APPLICATION MENU (OPTIONAL) / УСТАНОВКА В МЕНЮ (ПО ЖЕЛАНИЮ)
---------------------------------------------------------------------
EN: To add PDFuse to your system application menu, run:
RU: Чтобы добавить PDFuse в меню приложений, выполните:
    ./install.sh

EN: To remove it from the menu later:
RU: Чтобы удалить программу из меню позже:
    ./uninstall.sh


SYSTEM REQUIREMENTS / СИСТЕМНЫЕ ТРЕБОВАНИЯ
------------------------------------------
EN: Linux x86_64 with a graphical environment (X11 or Wayland).
RU: Linux x86_64 с графическим окружением (X11 или Wayland).

EN: FUSE 2 is required to run AppImage (usually already installed).
RU: Для запуска AppImage требуется FUSE 2 (обычно уже установлен).

EN: If it is missing, install it via:
RU: Если его нет, установите командой:
    sudo apt install libfuse2t64
